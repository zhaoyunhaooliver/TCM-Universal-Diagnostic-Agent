# 方剂整理

## 《伤寒论》方剂整理
1. 按中医六经辩证的方式分类症状、方剂、方剂组成和方后注 （包括白话文）按六经分类：太阳上、中、下，阳明，少阳，太阴，少阴，厥阴，另附霍乱和差后劳复。共 153 行，涉及 112 个方。每行有条号、症状原文和白话、方名、组成（保留原文剂量）、方后注原文和白话
2. 九个方族的比较表：桂枝汤族、麻黄汤与葛根汤族、柴胡汤族、泻心汤族、承气汤与攻下族、白虎汤与栀子豉汤族、四逆汤与附子类、茯苓理中吴茱萸类、陷胸与黄芩类。字段是相同组成、衍生方、变化的药、变化原因、对应症状、条号。

需要注意的地方

剂量差异：白虎加人参汤的人参，第 168 条是二两，其余是三两。吴茱萸汤的人参，第 309 条是二两，其余是三两。小柴胡汤第 394 条的人参、黄芩、甘草各二两，其他条是三两。调胃承气汤的芒硝，阳明篇第 207 条是半斤，其余是半升。这些在文件里都按各条原文保留，并列在第四部分。
原文存疑：桂枝加葛根汤原文含麻黄，林亿认为应当没有。甘草泻心汤原文无人参，林亿认为是脱漏。芍药甘草附子汤和黄连汤，原文注“疑非仲景方”。
只用了一个文本：没有和康平本、桂林古本等其他版本核对。原文里的“或”症是候选症状，不要求同时出现。
组成不全的方：禹余粮丸方阙，没有组成。第 277 条只说“四逆辈”，没有给方。土瓜根导法也没有给量。
